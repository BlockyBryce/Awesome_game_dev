# Game Development Careers and Programming Disciplines

## 1. Game Development Career Pathways

### 1. Level Designer

A Level Designer creates and organizes the levels and environments that players explore. They plan layouts, challenges, objectives, and player progression.

### 2. AI Game Programmer

An AI Game Programmer creates the systems that control computer-controlled characters. This can include enemy behavior, NPC decision-making, and pathfinding.

### 3. Quality Assurance (QA) Game Tester

A QA Game Tester plays and tests games to find bugs, glitches, crashes, and other problems before the game is released.

### 4. Game Illustrator

A Game Illustrator creates artwork used in games, including concept art, character designs, environments, and other 2D visual material.

### 5. Gameplay Animator

A Gameplay Animator creates animations for characters, creatures, objects, and gameplay actions.

### 6. Narrative Designer

A Narrative Designer works on the storytelling side of a game. They can create dialogue, characters, quests, storylines, and other narrative elements.

### 7. Technical Artist

A Technical Artist works between the art and programming sides of game development. They create tools and solve technical problems that help artists create and use game assets.

### 8. Asset Artist

An Asset Artist creates the visual objects used in games. These can include characters, props, environments, weapons, buildings, and other 2D or 3D assets.

### 9. Game Programmer

A Game Programmer writes the code that makes the game's features and systems work. They can work on many different parts of a game depending on their specialty.

### 10. Gameplay Engineer

A Gameplay Engineer programs the features that players directly interact with, such as movement, controls, combat, abilities, and gameplay mechanics.

### 11. Game Designer

A Game Designer develops the rules, mechanics, challenges, and overall player experience of a game.

### 12. Systems Designer

A Systems Designer creates and balances larger interconnected systems within a game. These can include progression, inventories, abilities, economies, and character systems.

## 2. Game Programming Disciplines

### 1. Gameplay Programming

Gameplay Programming focuses on the mechanics and interactions that players experience while playing a game.

**Job Titles:**

* Gameplay Programmer
* Gameplay Engineer

### 2. AI Programming

AI Programming creates the behavior and decision-making systems used by NPCs, enemies, and other computer-controlled characters.

**Job Titles:**

* AI Programmer
* AI Engineer

### 3. Physics Programming

Physics Programming handles physical interactions in a game, including collisions, gravity, movement, vehicles, and other simulated physical behavior.

**Job Titles:**

* Physics Programmer
* Physics Engineer

### 4. Graphics Programming

Graphics Programming focuses on how a game creates and displays its visuals. This can include rendering, lighting, shaders, and visual effects.

**Job Titles:**

* Graphics Programmer
* Rendering Engineer

### 5. Engine Programming

Engine Programming focuses on the underlying technology that allows a game to run. Engine programmers can work on systems used by many different parts of a game.

**Job Titles:**

* Engine Programmer
* Engine Engineer

### 6. Tools Programming

Tools Programming creates software and tools that help other developers build games more efficiently.

**Job Titles:**

* Tools Programmer
* Tools Engineer

### 7. Network Programming

Network Programming focuses on multiplayer communication and keeping game information synchronized between players and servers.

**Job Titles:**

* Network Programmer
* Multiplayer Engineer

### 8. UI Programming

UI Programming creates the code behind menus, HUDs, inventory screens, settings, and other interfaces that players interact with.

**Job Titles:**

* UI Programmer
* UI Engineer

### 9. Audio Programming

Audio Programming creates the systems that control interactive sound, music, sound effects, and other audio features in games.

**Job Titles:**

* Audio Programmer
* Audio Engineer

### 10. Systems Programming

Systems Programming focuses on larger game systems that support different parts of the game, such as progression, saving, resources, and other interconnected features.

**Job Titles:**

* Systems Programmer
* Technical Programmer
